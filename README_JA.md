[LaunchOS](https://launchosapp.com/?utm_source=github&utm_medium=readme) は、macOS 26 と macOS 27 のために作り直された Launchpad 代替ツールです。小さなインストーラーだけで、クラシックな Launchpad の操作体験を取り戻せます。最大の特徴は、ネイティブ Launchpad の操作感と筋肉記憶をそのまま残していることです。滑らかで自然に使え、さらにネイティブ体験の上に実用的な改善も加えています。軽量で、控えめで、細部まで磨き込まれており、ネイティブ Launchpad の体験を高い精度で再現しながら、新しいシステムの Liquid Glass スタイルにも自然に馴染みます。

日々の効率を本当に左右する小さな細部を作り直し、Apple が提供してこなかった実用的な強化も加えました。macOS 26 と macOS 27 で、より自然で、より完全で、より強力な Launchpad 体験を提供します。

## LaunchOS V2 の主な変更点

- LaunchOS V2 は土台から作り直され、SwiftUI から AppKit へ移行しました。
- 起動後の初回表示速度、実行時のパフォーマンス、アニメーションを大幅に改善しました。
- 120Hz 以上の高リフレッシュレート表示にネイティブ対応しました。

V2 はより速く、より滑らかで、より省電力、さらにメモリ使用量も少なくなりました。




## FAQ

**この製品は無料ですか？**

LaunchOS には無料の Basic プランと、7 日間の無料トライアル付き Pro プランがあります。多くのユーザーにとって、Basic プランだけでも日常利用には十分です。

**ライセンスメールが届かない場合はどうすればよいですか？**

お支払い後、領収書とライセンスメールの 2 通が届きます。ライセンスメールは領収書より数分遅れて届く場合があります。
領収書のみが届いた場合は、迷惑メールフォルダを確認してください。プロバイダーによって迷惑メールとして分類されている可能性があります。
どちらのメールも届かない場合は、入力したメールアドレスが間違っているか、メールサービスで受信できない状態である可能性があります。
どのような状況でもご安心ください。以下のメールアドレスまでお問い合わせいただければ解決いたします。

**ライセンスが無効と表示された場合はどうすればよいですか？**

ライセンスをコピーする際に、余分な文字、空白、改行などが含まれていないか確認してください。
一度プレーンテキストエディタに貼り付けてから、もう一度アプリにコピーしてみてください。
問題が続く場合は、以下のメールアドレスまでお問い合わせください。

**デバイスを買い替えた場合、ライセンスを再購入する必要がありますか？**

再購入の必要はありません。デバイスを変更する場合は、アクティベーションプロセス中に古いデバイスを削除してください。また、「設定 > バージョン情報 > デバイス管理」でもデバイスを管理できます。

**新しいメジャーバージョンへアップグレードする場合、ライセンスを再購入する必要がありますか？**

いいえ、再購入の必要はありません。すべての購入には、今後のメジャーバージョンへのライフタイム無料アップグレードが含まれます。
