[LaunchOS](https://launchosapp.com) 是一款為 macOS 26 與 macOS 27 重新打磨的 Launchpad（啟動台）替代產品，只需要一個小小的安裝包，就能恢復經典啟動台的操作體驗。它最大的特色，是完整保留原生啟動台的操作手感與肌肉記憶，使用時順滑流暢，並在原生體驗之上加入增強最佳化功能。它輕量、克制、細緻打磨，從視覺風格到互動手感，在極致還原原生啟動台體驗的同時，也與新系統的 Liquid Glass 風格自然融合。

我們重新打磨了那些真正影響日常效率的小細節，也補上了 Apple 一直沒有提供的幾項實用增強，讓它成為 macOS 26 與 macOS 27 上更自然、更完整，也更強大的 Launchpad 體驗。

## LaunchOS V2 核心變化

- LaunchOS V2 從底層重新構建，從 SwiftUI 遷移至 AppKit；
- 大幅改進了開機後首次打開的啟動速度、執行效能、動畫表現；
- 原生支援 120Hz 和更高刷新率螢幕。

V2 版本更快、更順滑、更省電，也更節省記憶體！




## 常見問題

**這款產品是免費的嗎？**

LaunchOS 提供免費基礎版，也提供帶 7 天免費試用的 Pro 版本。對很多使用者來說，基礎版已經足夠滿足日常使用。

**我沒有收到授權郵件怎麼辦？**

付款後，您將收到兩封郵件：收據郵件和授權郵件，授權郵件可能會比收據郵件稍晚幾分鐘到達。
如果您只收到了收據郵件，請檢查您的垃圾郵件資料夾，因為授權郵件可能會被您的電子信箱誤判為垃圾郵件過濾。
如果您兩封郵件都沒有收到，這通常意味著您在下單時填寫了錯誤的電子郵件地址，或者您的電子信箱無法正常接收郵件。
不論您遇到哪種情況，請不用擔心，透過下面的電子信箱聯絡我們來為您解決。

**提示我授權無效怎麼辦？**

請確認您在複製授權序號時沒有複製任何額外字元，比如空格或換行符。
嘗試先將序號貼到純文字編輯器中，然後再複製回應用程式裡。
如果問題仍然存在，請透過下面的電子信箱聯絡我們。

**更換裝置時，需要重新購買授權嗎？**

您無需重新購買。如果您更換了裝置，只需要在啟用的時候移除舊裝置即可，您也可以在「設定 > 關於 > 裝置管理」介面中管理您的裝置。

**升級到新的大版本後，需要重新購買授權嗎？**

不需要。所有購買均包含後續大版本的終身免費升級。
