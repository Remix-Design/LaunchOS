我们重新打磨了那些真正影响日常效率的小细节，也补上了 Apple 一直没有提供的几项实用增强，让它成为 macOS 26 上更自然、更完整，也更强大的 Launchpad 体验。

## 常见问题

**这款产品是免费的吗？**

LaunchOS 提供免费基础版，也提供带 7 天免费试用的 Pro 版本。对很多用户来说，基础版已经足够满足日常使用。

**我没有收到许可证邮件怎么办？**

付款后，您将收到两封邮件：收据邮件和许可证邮件，许可证邮件可能会比收据邮件稍晚几分钟到达。
如果您只收到了收据邮件，请检查您的垃圾邮件文件夹，因为许可证邮件可能会被您的邮箱误判为垃圾邮件过滤。
如果您两封邮件都没有收到，这通常意味着您在下单时填写了错误的邮箱地址，或者您的邮箱无法正常接收邮件。
不论您遇到哪种情况，请不用担心，通过下面的邮箱联系我们来为您解决。

**提示我许可证无效怎么办？**

请确保您在复制许可证时没有复制任何额外字符，比如空格或换行符。
尝试先将代码粘贴到纯文本编辑器中，然后再复制回应用里。
如果问题仍然存在，请通过下面的邮箱联系我们。

**更换设备时，需要重新购买许可证吗？**

您无需重新购买。如果您更换了设备，只需要在激活的时候移除旧日设备即可，您也可以在设置-关于-设备管理界面中管理您的设备。

**升级到新的大版本后，需要重新购买授权吗？**

不需要。所有购买均包含后续大版本的永久免费升级。
